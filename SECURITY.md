## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue,
please follow the responsible disclosure process below.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

### How to Report

1. **Email**: Send a detailed report to `security@tanteijms.dev`
2. **GitHub Private Reporting**: Use [GitHub private vulnerability reporting](https://github.com/tanteijms/repository-health-audit/security/advisories/new)
3. **Encrypted Communication**: PGP key available upon request for sensitive reports

### What to Include in Your Report

- Description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Affected versions
- Any suggested fixes (optional but appreciated)
- Your contact information for follow-up

### Response Timeline

- **Acknowledgment**: Within 48 hours of receiving your report
- **Initial Assessment**: Within 5 business days
- **Status Updates**: Every 7 days until resolution
- **Resolution Target**: Critical issues within 30 days

## Responsible Disclosure Process

We follow coordinated disclosure:
1. Reporter submits vulnerability privately via email or GitHub private advisory
2. We acknowledge receipt and begin investigation
3. We develop, test, and deploy a fix
4. We publicly disclose the vulnerability after the fix is released
5. We credit the reporter (unless they prefer to remain anonymous)

We kindly ask that you:
- Give us reasonable time to fix the issue before public disclosure
- Not exploit the vulnerability beyond what is necessary to demonstrate it
- Not access, modify, or delete other users data

## Recognition

We appreciate security researchers who help keep this project safe.
Reporters who follow responsible disclosure will be acknowledged in our
release notes unless they prefer to remain anonymous.
